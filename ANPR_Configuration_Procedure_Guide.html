TECHNICAL REFERENCE MANUAL

ANPR Camera Webhook Integration & Configuration Guide

System: Smart Hospital Car Parking & Visitor Validation Solution | KIMSHEALTH Bahrain

1. Architecture & Real-Time Flow

The parking solution interfaces directly with ANPR cameras at entry and exit gate lanes. When a vehicle passes through a lane, the camera captures the plate number and pushes an HTTP POST webhook request containing JSON metadata and snapshot images. The system processes the event in under 80 milliseconds, evaluates access permissions, controls the boom barrier, and tracks parking tariffs.

⚡ Decision Engine Response Time: < 80ms.
🔒 Whitelist / Emergency / Prepaid Passes: Instant automated boom barrier opening with fee waiver (BD 0.000).
⏱️ Unvalidated Visitors: Entry barrier opens, grace period countdown starts, and automated tariff charging commences if unvalidated after grace minutes.

2. Webhook URLs to Configure in Camera Software

Choose the target URL based on whether the camera is communicating on a Local Area Network (LAN) or Cloud WAN:

Option A: Local Network (On-Premise LAN IP)

Recommended for hospital sites where cameras and this computer are plugged into the same local router or switch:

http://192.168.100.4:8000/api/v1/webhook/anpr

* Note: Replace 192.168.100.4 with the static LAN IP assigned to your server machine by the hospital IT team.

Option B: Production Cloud Server (Domain Name)

For cloud-hosted deployments where cameras push over the public internet with SSL encryption:

https://parking.sandslab.com/api/v1/webhook/anpr

Option C: Localhost (Testing on Same PC)

http://127.0.0.1:8000/api/v1/webhook/anpr

3. Dahua ANPR Camera Configuration (Step-by-Step)

Supported Models: Dahua DHI-ITC413-PW4D, ITC237, ITC215, and all Dahua Traffic ITS cameras.

Step 3.1: Enable Road Traffic Detection

  1. Open browser and navigate to camera IP (default: http://192.168.1.108).
  2. Login with camera admin credentials.
  3. Go to: Setting → Event → Traffic Recognition (or Road Traffic).
  4. Check Enable Road Traffic. Set Region to Bahrain (BHR) or GCC.
  5. Click Save.

Step 3.2: Configure HTTP Push Webhook

  1. Go to: Setting → Network → Access Platform → HTTP Push (or Alarm Server).
  2. Configure the settings:
    • Enable: Checked
    • Protocol: HTTP
    • Method: POST
    • Destination IP: 192.168.100.4 (Your Host Server IP)
    • Port: 8000
    • Request Path / URL: /api/v1/webhook/anpr
    • Data Format: JSON (UTF-8)
    • Upload Pictures: Check Plate Picture & Panoramic Overview Picture.
  3. Click Save and Apply.

Dahua JSON Payload Format Sent to Server:

{
  "PlateNumber": "BHR 55443",
  "PlateColor": "Blue",
  "VehicleColor": "Silver",
  "VehicleType": "Sedan",
  "TimeStamp": "2026-09-10 12:45:00",
  "Channel": 1,
  "Lane": 1,
  "SnapPicURL": "http://192.168.100.20/snapshot/img1.jpg"
}

4. Hikvision ANPR Camera Configuration

Supported Models: DS-2CD7A series, iDS-TCM403, iDS DeepinView Traffic IPC.

  1. Navigate to: Configuration → Network → Advanced Settings → HTTP Listening (or Alarm Server).
  2. Set:
    • Destination Address: 192.168.100.4
    • Port: 8000
    • URL: /api/v1/webhook/anpr
    • Protocol: HTTP POST
    • Picture Upload: Enabled (Plate Cutout & Overview Snapshot).
  3. Under Road Traffic → Vehicle Detection, ensure region is GCC / Bahrain.
  4. Click Save.

6. Camera Snapshot Storage Folder Path

Incoming camera vehicle photos (Base64 data, multipart binary uploads, or snapshot links) are automatically stored onto disk:

Configured Directory: storage/uploads/anpr_snapshots
Host Disk Absolute Path: E:\parkingsolution\backend\storage\uploads\anpr_snapshots
File Naming Format: [PLATE]_[DIRECTION]_[YYYYMMDD_HHMMSS]_[RAND].jpg
Example: BHR_55443_entry_20260910_124500_91a2.jpg

Images stored here are directly indexed and visible in Parking Sessions, Live Monitor, and Audit Trails.

7. Boom Barrier Relay Hardware Configuration

The system triggers barrier opening via Ethernet IP Relay modules (Dry Contact NO/COM pulse):

  • Relay Wiring: Connect Relay Channel 1 (COM and NO terminals) to the Boom Barrier motherboard's Open Signal dry contact input.
  • Relay Pulse Duration: 800 ms (Configurable in Settings).
  • Entry Barrier Relay Target: 192.168.1.201:8080 (Gate: GATE-IN-01)
  • Exit Barrier Relay Target: 192.168.1.202:8080 (Gate: GATE-OUT-01)
  • Relay Command: RELAY_CH1_PULSE

8. Prepaid Passes & Automatic Whitelisting

For vehicles paying for Day, Week, or Month parking passes:

  1. Go to Prepaid Passes in the top menu → click + Issue New Prepaid Pass.
  2. Enter Start Date, Duration Plan (Day/Week/Month), Plate Number, Vehicle Type, Owner Name, Contact Phone, and Payment Method (Cash, BenefitPay QR, Card).
  3. Click Confirm & Issue Prepaid Pass.
Automatic Whitelisting Effect:
The vehicle is immediately inserted into the vehicles table with access_status = 'whitelisted'.
When the ANPR camera detects the vehicle, the Decision Engine automatically recognizes the active pass, opens the boom barrier, waives the parking fee (BD 0.000), and records the transaction in the Financial and Vehicle-Specific Ledgers.

9. Field Verification & Troubleshooting

Symptom Possible Cause Resolution
Camera posts event but fails with timeout Windows Firewall blocking Port 8000 Run: New-NetFirewallRule -DisplayName "ANPR Webhook" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
Server returns HTTP 400 "Plate not detected" JSON column key mismatch In System Settings, select the camera manufacturer preset (e.g., Dahua) or check exact plate field name.
Plate detected but barrier doesn't open Relay IP offline or cable disconnected Check Ethernet cable to IP relay (e.g. 192.168.1.201). Test barrier manually with physical push button.
Prepaid vehicle charged a fee Pass expired or plate typed with different spaces Verify pass in Prepaid Passes registry; spaces are automatically normalized.
